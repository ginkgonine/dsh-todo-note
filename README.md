# DSH TODO-NOTE

为 **DeepSeek Harness（DSH）Web** 提供轻量待办与笔记管理。在侧边栏记录任务、安排截止日期，并将待办交给 agent 继续处理。

**当前版本：v1.0.1** · [项目仓库](https://github.com/ginkgonine/dsh-todo-note) · [版本列表](https://github.com/ginkgonine/dsh-todo-note/tags)

## 功能

- **快速添加**：在底部输入标题，回车创建待办。
- **任务管理**：完成勾选、笔记编辑、搜索与状态筛选。
- **截止日期**：设置到期日，查看今天到期和逾期事项。
- **月历视图**：按日期浏览待办，在选定日期下直接添加任务。
- **Agent 协作**：在对话中创建、修改待办，或从待办开启新的 agent 对话。
- **持久保存**：待办保存在 DSH Host，刷新页面或重启后保留。
- **轻量界面**：侧边栏浮动卡片，不占用聊天主工作区，跟随明暗主题。

## 安装

需要支持插件管理、工作区和 agent 对话的 DSH Web 环境。兼容性验证基于 DSH `0.2.0-rc.1`。

### 从 GitHub 安装

在 DSH 中打开 **插件 → 添加插件**，输入：

```text
github:ginkgonine/dsh-todo-note#v1.0.1
```

安装并启用后，侧边栏底部会出现 **TODO**。

也可通过命令行安装：

```sh
dsh plugin --profile web add "github:ginkgonine/dsh-todo-note#v1.0.1"
```

`web` 是目标 profile。使用自定义 profile 时，请替换为实际名称。安装结果提示需要重启时，重启 DSH 后刷新页面。

### 从本地目录安装

```sh
git clone https://github.com/ginkgonine/dsh-todo-note.git
```

在插件管理器中填写克隆目录的绝对路径，或执行：

```sh
dsh plugin --profile web add /absolute/path/to/dsh-todo-note
```

本地目录必须位于运行 DSH Host 的机器上。安装无需手动构建或发布到 npm。

> 插件在 DSH Host 中运行，请仅安装可信来源的代码。

## 使用

### 添加与管理待办

1. 点击侧边栏底部 **TODO**，打开待办卡片。
2. 在底部 **＋ 添加待办** 输入标题，按回车创建。
3. 点击 **编辑**，补充笔记或设置截止日期。
4. 完成后勾选复选框；取消勾选可恢复为未完成。

默认显示全部事项，未完成在前、已完成在后。可切换 **全部 / 待完成 / 已完成**，或点击右上角搜索图标展开搜索框。

再次点击 **TODO**、点击卡片外的区域、按 **Esc** 或点击 **×** 均可关闭。TODO 入口始终保留，卡片外的点击仍可正常操作 DSH。

**删除会直接永久移除待办，不提供撤销或回收站。**

### 截止日期与日历

在事项的 **编辑** 中设置或清除截止日期。未完成事项会标注 **今天到期** 或 **已逾期**。

点击右上角日历图标打开月历：

- 切换月份，或点击 **今天** 返回当前日期。
- 有到期事项的日期显示圆点，点击日期查看当天待办。
- 点击 **全部日期**，查看所有事项，包括未设置截止日期的待办。
- 选中某天后，底部新增事项会自动使用该日期作为截止日期。
- 点击日历底部 **收起日历**，返回待办列表。

截止日期按天管理，今天按浏览器本地日期判断。目前不提供具体时刻、自动提醒或重复任务。

### 与 Agent 协作

可以在 DSH 对话中直接提出需求，例如：

> 添加一个待办：整理项目文档。
>
> 将这三个任务加入 TODO，并设置各自的截止日期。
>
> 把“整理项目文档”标记为完成。

Agent 通过 `todo_note` 工具管理与卡片相同的待办数据。卡片已打开时，可点击右上角刷新查看修改。

也可以从某条待办发起对话：

1. 点击 **发起 agent 对话**。
2. 选择侧边栏已有的工作区。
3. 点击 **创建并发送**。

新对话归入所选工作区，并使用其工作目录。待办的标题、笔记和截止日期会发送给 agent。点击 **打开对话** 可返回该事项最近创建的会话。

Agent 对话仍遵循 DSH 的权限与审批设置，可能产生模型调用费用；对话结束不会自动将待办标记为完成。

## 更新与卸载

### 更新

GitHub 安装建议明确指定目标版本：

```sh
dsh plugin --profile web add "github:ginkgonine/dsh-todo-note#v1.0.1"
```

更新到后续版本时，将 tag 替换为对应版本。**更新后重启 DSH，再刷新 Web 页面。**

本地目录安装可更新克隆目录的代码后重启 DSH。

### 禁用或卸载

在插件管理器中找到 **TODO 笔记 / TODO Notes**，关闭开关即可禁用；详情页可卸载插件。

命令行卸载：

```sh
dsh plugin --profile web remove @local/dsh-todo-note
```

卸载插件不会主动删除已保存的待办数据。

## 数据与隐私

- 待办保存在 DSH Host 的持久化存储中，不保存在浏览器或 GitHub 仓库。
- 本插件不提供跨设备同步。不同 Host 的数据不会自动共享。
- 备份应包含 DSH Host 的存储数据，仅备份插件源码不能恢复待办。
- 请避免降级到较早版本，以免旧版无法读取新版数据。
