# DSH TODO-NOTE

一个直接集成到 DSH Web 前端的轻量待办 / 笔记插件。

## 使用

- 侧边栏底部点击 **TODO**，在左下方弹出宽约 360px 的竖向卡片，不切换主聊天工作区。
- 再点 TODO、卡片的 × 或按 Escape 关闭卡片。卡片不阻塞其余界面。
- 底部固定 **添加待办** 输入区：点击输入标题，回车直接创建。中文输入法确认候选词的回车不会创建；更多笔记内容可在事项的「编辑」中补充。
- 默认显示「全部」，未完成排前、已完成排后。同组按创建时间排列，编辑不会让事项跳位。
- 勾选时即时更新对应行，不刷新整个列表、不让整张卡片变灰；提交失败会还原该行并显示错误。
- 右上角搜索图标展开输入框；再点图标或搜索框内按 Escape 会清空并收起搜索。
- 在「编辑」中设置或清除 **截止日期**（按天，不包含具体时刻和自动提醒）。未完成事项标注今天到期 / 已逾期；完成后不再标红逾期。日期按浏览器本地的今天判断。
- 右上角日历图标切换 **月历**：周一开始，可切换月份、回到今天；有到期事项的日期显示小圆点。点击日期查看当天到期待办，「全部日期」包含未设置日期的事项。状态和搜索过滤同时生效。
- 日历选中某天时，底部快速添加会自动采用这一天作为截止日期，输入框占位显示选定日期；普通列表或「全部日期」中快速添加不自动设日期。
- 支持全部 / 待完成 / 已完成筛选、编辑。点击「删除」直接永久移除待办，无二次确认；失败时保留待办并显示错误。
- 卡片跟随 DSH 明暗主题，支持的浏览器显示轻微半透明磨砂背景，不支持磨砂时退回主题色实底。列表单独滚动，添加区不会随列表滚走。
- **发起 agent 对话**：从下拉列表选择已有工作区（与侧边栏一致，显示名称和固定目录），点击「创建并发送」。插件使用工作区 ID 创建独立会话，对话归入该工作区，并使用其固定目录；将当前已保存的标题和笔记作为用户输入发送，并打开会话。没有工作区时请先在侧边栏添加；工作区失效或加载失败时不允许发送，不会悄悄退回「未分组」。
- **打开对话**：回到这条待办最近创建的会话。完成会话不会自动勾选待办。
- TODO 数据属于当前 DSH Host / 配置环境的插件存储，不属于某一条聊天会话，也不是浏览器 localStorage。刷新页面和重启后保留；卸载插件不会主动删除数据。
- 页面打开时加载最新数据，其他页面或 agent 改动后可点击「刷新」。

## Agent 工具

Host 注册 `todo_note`，和页面复用同一套操作。动作：

| action | 参数 | 结果 |
| --- | --- | --- |
| list | 无 | notes |
| list_workspaces | 无 | workspaces（id / title / path） |
| create | title，body / completed / dueDate 可选 | note |
| update | id，加 title / body / completed / dueDate 至少一项 | note |
| delete | id | id，deleted |
| start_chat | id，workspaceId 推荐；cwd 为兼容参数，与 workspaceId 互斥 | sessionId |

`dueDate` 是真实日期 `YYYY-MM-DD`（0001–9999 年），传 `null` 清除，更新时省略则保留原日期。旧待办默认无日期，不会丢失；从待办发起对话时也会传递截止日期。

删除永久移除笔记；启动对话可能产生模型调用费用，但不会提高权限。操作失败返回 `ok:false` 和 `error`。若新会话创建后发送失败，`error.sessionId` 可用于打开已创建会话，避免重复创建。

## 安装

在 DSH 插件管理器安装本项目绝对目录，或使用 `plugin_manager install_bundle`。包名：`@local/dsh-todo-note`。Bundle 插入 `dsh-todo-note` 行。

当前本地部署的 patch 直接引用本项目 Host 文件的绝对路径，避免此前失败模块的运行时缓存。如果移动项目目录，需同步修改 patch 的 `name` 路径再安装；此项目当前针对本机使用。替换已安装包的代码通常需要重启 DSH，不能仅凭相同 slot id 认为更新已生效。

页面发起对话必须选择工作区，工作目录由该工作区决定。Agent 工具应先调用 `list_workspaces`，再用 `workspaceId` 发起对话。旧工具调用仍兼容 `cwd`：匹配已注册工作区时自动归入，无匹配时才创建未分组会话。仅旧工具调用省略工作区和目录时使用默认 `/home/ubuntu/dsh-todo-note`，可通过插件行 `config.cwd` 配置。

更新 Host 代码后需要重启 DSH；仅刷新页面不会替换已加载的 Host 模块。已有未分组会话不会自动迁移，可在侧边栏将其拖入对应工作区（目录必须匹配）。

截止日期版使用存储版本 2，同时兼容旧版本 1；未修改的旧记录不会自动重写。请不要直接回退到旧 Host 入口：旧版不识别版本 2 的记录，可能看不到新建或已修改事项，尽管磁盘文件仍存在。

## 开发 / 验证

原生 JavaScript，无前端构建步骤；使用 DSH 的 React 模块、slot、locale 和主题 token，不导入 Harness 私有 UI 组件。

```sh
npm install --ignore-scripts
npm test
node --check client.js
```
